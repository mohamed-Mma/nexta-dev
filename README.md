# Nexta dev

Static site for developer commands (Git + PowerShell).

Open `index.html` in a browser, or deploy the folder to GitHub Pages / Netlify / Vercel.

No build step, no dependencies.

## Structure

- `css/style.css` — styles
- `js/app.js` — helpers, rendering, search, events, tabs
- `js/git.js` — Git commands data, Quick Push, Workflow Builder
- `js/powershell.js` — PowerShell commands
- `js/generator.js` — Command Generator + history
- `js/i18n.js` — Arabic / English
- `js/main.js` — init

## Sections

1. **Hero** — Search + Quick Actions
2. **Git Tools** — Quick Push + Workflow Builder (tabs)
3. **Commands Library** — Git / PowerShell (switch + filters)
4. **Command Generator**
5. **Favorites**
6. **About**
