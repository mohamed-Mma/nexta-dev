أدخل بياناتك واحصل على أوامر جاهزة. الموقع يولّد الأوامر فقط ولا ينفذ شيئًا على جهازك.

⚠ Force Push قد يستبدل تاريخ الريبو وتغييرات موجودة عليه بشكل لا يمكن التراجع عنه. استخدمه فقط إذا كنت تفهم أثره.
  1. أنشئ ريبو فارغًا على GitHub (للرفع الجديد).
  2. افتح PowerShell داخل مجلد المشروع، أو أدخل مساره ليُضاف أمر cd.
  3. الصق الأوامر بالترتيب، وسجّل دخولك إلى GitHub إذا طُلب منك.
